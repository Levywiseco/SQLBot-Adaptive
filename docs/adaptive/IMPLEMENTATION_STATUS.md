## 当前事实边界

本地环境没有配置系统默认 LLM，因此已经验证的是数据库、API、权限、检索合同、UI 和合成结果，尚未声称真实 Text-to-SQL 正确率达标。Embedding 暂时关闭，当前记忆召回采用作用域过滤后的确定性关键词与偏好排序。真实业务正确率、泛化率、延迟和成本必须在模型与业务样本到位后测量。
